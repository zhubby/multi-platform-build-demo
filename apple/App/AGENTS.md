# App/
> L2 | Parent: ../AGENTS.md

TaskNotesApp.swift: 两个独立应用 target 共用的场景与缓存装配。
RootView.swift: 原生侧栏、搜索、完成筛选、列表和连接状态。
Editors.swift: 任务与笔记草稿、删除确认、冲突核对和嵌套连接入口。
ConnectionView.swift: 地址持久化、仅内存令牌输入与保留外层草稿的连接窗口。
Info-ios.plist: iOS 应用身份、启动屏与内网 HTTP 开发配置。
Info-macos.plist: macOS 应用身份与内网 HTTP 开发配置。
